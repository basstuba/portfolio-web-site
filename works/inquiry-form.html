お問い合わせフォームの開発

区分

個人開発

期間

2025年7月（2週間）

概要

プログラミングスクールでLaravelを使って作成した課題を、Djangoで再実装しました。別のフレームワークでも同じ機能を一から構築できることを確かめるためのアウトプットです。

機能一覧

  • ログイン及びログアウト機能
  • 管理者アカウント作成機能
  • お問い合わせ送信機能
  • お問い合わせ内容確認画面表示機能
  • サンクスページ表示機能
  • お問い合わせ一覧表示機能
  • お問い合わせ検索機能
  • お問い合わせ削除機能
  • エクスポート機能（お問い合わせ一覧をExcelで出力）
  • ページネーション機能

使用技術

言語

  • CSS
  • Python

フレームワーク

DB・ツール

  • Docker
